# Photomosaic

This program attempts to re-create a target image using only a collection of other images as its pallette by running an evolutionary algorithm to mutate candidate images to better resemble the target
This project is intended to be an improved attempt of my original project ShapeScape (LINK), which was limited to basic shapes with flat colors, and was poorly created for a university assignment
